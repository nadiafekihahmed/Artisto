
# Artisto

An interactive 3D art platform developed as a collaborative project, combining mobile development, 3D visualization, and real-time auction experiences.

## Overview

Artisto explores how digital art can become more immersive and interactive through 3D technologies. The project brings together a mobile application and a backend system to support interactive art experiences and auction-related functionality.

## Tech Stack

- **Mobile:** React Native
- **3D Visualization:** Three.js
- **Backend:** Node.js
- **Database:** MongoDB
- **Real-time Communication:** Socket.IO

## Key Areas

- Interactive 3D experiences for digital artwork.
- Auction-related functionality.
- Real-time communication between application components.
- Integration between the mobile application and backend services.

The project is organized around a mobile application and backend components. Explore the source directories for implementation details.
